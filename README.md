- ⚫ **Pure Black Background** (#000000)

- 📸 **Grayscale Images** with color on hover
- ✨ **Glowing Shadows** on lime elements

## 🚀 Quick Setup

**1. Start MongoDB:**
```bash
mongod
```

**2. Backend:**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

**3. Frontend:**
```bash
cd frontend
npm install
npm run dev
```

**Access:**
- Frontend: http://localhost:3000
- Backend: http://localhost:8000
- Admin: admin@challengefitness.com / admin123
